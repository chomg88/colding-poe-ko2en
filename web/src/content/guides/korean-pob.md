한글 Path of Building 을 써 보면 이상한 지점들이 있습니다. 화면은 한글인데 아이템을
붙여넣으면 인식하지 못하고, 리그가 바뀌면 번역이 군데군데 비고, 어떤 옵션은 한글이고
어떤 옵션은 영문 그대로입니다.

이게 왜 그런지는 한글 POB 가 어떻게 만들어졌는지를 보면 알 수 있습니다.

## 번역판이 아니라 껍데기입니다

한글 POB 배포본을 열어 보면 안에 `Path of Building.exe` 와 함께 정체 모를 실행 파일이
하나 더 있습니다. **PoeCharm3** 라는 프로그램입니다.

구조는 이렇습니다.

```
PoeCharm3.exe          ← 실제로 실행되는 것
├─ Data/Translate/ko-KR/*.csv    번역 사전
└─ POE1 POB/                     손대지 않은 원본 Path of Building
```

`POE1 POB` 안에 있는 것은 **영문 원본 그대로입니다.** Lua 코드 한 줄 고쳐져 있지 않습니다.
PoeCharm3 는 원본을 실행하면서 화면에 글자가 그려지는 순간에 끼어들어 영문을 한글로
바꿔치기합니다.

원래는 중국 유저가 만든 중문화 도구입니다. 한국 유저들은 여기에 중문 사전 대신 한글
사전을 넣어 쓰고 있습니다.

## 사전은 그냥 두 칸짜리 표입니다

번역의 실체는 CSV 파일 118개, 약 127만 줄입니다. 내용은 놀랄 만큼 단순합니다.

```
"{0}% increased maximum Life","최대 생명력 {0}% 증가"
"Astramentis","별의 보석"
"Ebony Tower Shield","칠흑의 거대 방패"
```

왼쪽이 영문, 오른쪽이 한글. `{0}` 은 숫자가 들어갈 자리입니다.

화면에 글자를 그릴 때마다 이 표에서 찾아 바꿉니다. 숫자는 미리 지워서 맞춰 봅니다.
`최대 생명력 45% 증가` 를 찾을 때 숫자를 뺀 `최대 생명력 % 증가` 로 표를 뒤지고,
찾으면 원래 숫자를 도로 끼워 넣는 식입니다.

**표에 없으면 그냥 영문이 나옵니다.** 새 리그가 나오면 옵션이 추가되는데 사전이 아직
갱신되지 않았으면 그 줄만 영문으로 남습니다. 번역이 군데군데 비는 이유가 이것입니다.

## 그래서 아이템 붙여넣기가 안 됩니다

여기서부터가 실제로 불편한 지점입니다.

PoeCharm3 안에는 붙여넣은 아이템을 되돌리는 기능이 실제로 들어 있습니다. 아이템
입력칸에 붙여넣기 필터가 걸려 있고, 거기서 현지어를 영문으로 바꾸는 코드가 호출됩니다.

문제는 **그 코드가 중국어 전용**이라는 것입니다. 프로그램 안에 압축돼 들어 있는 번역
엔진을 꺼내 보면 데이터가 전부 이런 모양입니다.

```
{ en: "Coral Amulet", zh: "珊瑚护身符" }
{ en: "Araku Tiki",   zh: "隐灵之符" }
```

한글은 한 글자도 없습니다. 한국 배포판은 **화면 표시용 사전만 교체했고 역방향 엔진은
손대지 않았습니다.** 그래서 한글 클라이언트에서 복사한 아이템을 붙여넣어도 이 경로가
동작하지 않습니다.

## 한글 POB를 쓸까, 영문 POB를 쓸까

정리하면 이렇습니다.

**한글 POB 가 나은 경우** — 패시브 트리와 옵션을 한글로 읽고 싶을 때. 특히 시작한 지
얼마 안 됐다면 트리 노드 설명이 한글로 나오는 것이 큰 차이입니다.

**영문 POB 가 나은 경우** — 해외 빌드 가이드를 그대로 가져와 쓸 때, 그리고 최신 리그
대응이 필요할 때. 영문 POB 는 원 개발자들이 바로 갱신하지만, 한글 사전은 그 뒤에
따라옵니다.

둘 다 쓰는 방법도 있습니다. 빌드를 짤 때는 한글로 보고, 아이템을 옮기거나 남의 빌드를
불러올 때는 영문을 쓰는 식입니다. 빌드 코드는 양쪽이 같은 형식이라 그대로 오갑니다.

한글 클라이언트에서 복사한 아이템을 영문 POB 에 넣어야 한다면
[아이템 변환기](/)를 쓰시면 됩니다. 위에서 설명한 그 사전을 거꾸로 뒤집어 만든 도구입니다.

## 사전을 직접 갱신할 수도 있습니다

`Data/Translate/ko-KR/` 폴더의 CSV 는 그냥 텍스트 파일입니다. 번역이 빈 옵션을 발견하면
`"영문","한글"` 형식으로 한 줄 추가하고 POB 를 다시 켜면 반영됩니다.

파일이 여러 개인데 어느 것에 넣어도 상관없습니다. 프로그램은 폴더 안의 `*.csv` 를 전부
읽어 하나의 표로 합칩니다.
