고급 아이템 정보 표시를 켜면 아이템 툴팁이 훨씬 길어집니다. 옵션마다 중괄호로 둘러싸인
줄이 하나씩 붙고, 수치 뒤에는 괄호가 따라옵니다.

```
{ 접두어 속성 부여 "압도하는" (등급: 2) — 피해, 원소, 공격 }
공격 스킬의 원소 피해 38(37-42)% 증가
```

여기 담긴 정보를 하나씩 뜯어 보겠습니다.

## 중괄호 줄의 구조

한 줄에 네 가지가 순서대로 들어갑니다.

```
{ 접두어    속성 부여   "압도하는"   (등급: 2)   — 피해, 원소, 공격 }
  ────────  ─────────   ──────────   ─────────    ───────────────────
  종류                  이름          등급         분류 태그
```

**종류** — 이 옵션이 어디서 왔는지입니다.

| 표기 | 뜻 |
|---|---|
| 접두어 / 접미어 | 일반적인 무작위 옵션. 아이템 이름 앞뒤에 붙는 그 접사입니다 |
| 고정 속성 | 베이스타입에 원래 붙어 있는 옵션 |
| 대가의 제작 | 제작대에서 붙인 옵션 |
| 인챈트 / 각인 | 미궁이나 제단에서 붙인 옵션 |
| 균열된 · 합성된 | 균열·합성 아이템의 고정 옵션 |
| 세계 포식자 · 작열의 총주교 | 엘드리치 고정 속성 |

**이름** — 옵션 자체의 이름입니다. 접두어 `압도하는` 은 아이템 이름에도 실제로 들어갑니다.
희귀 아이템이 아니라 마법 아이템이었다면 이름이 `압도하는 ○○` 이 됐을 겁니다.

**등급** — 숫자가 작을수록 상위입니다. `등급: 1` 이 그 옵션의 최상위 구간입니다.
같은 옵션이라도 등급에 따라 수치 범위가 다릅니다.

**분류 태그** — 이 옵션이 어떤 계열로 분류되는지입니다. 제작할 때 중요합니다.
`피해, 원소, 공격` 이면 이 옵션은 세 계열 모두에 속하고, 해당 계열을 대상으로 하는
제작 방식에 걸립니다.

## 수치 뒤 괄호

```
공격 스킬의 원소 피해 38(37-42)% 증가
```

`38` 이 실제 값이고, `(37-42)` 가 **이 등급에서 나올 수 있는 범위**입니다.
38이면 37~42 중에서 거의 최하단이라는 뜻입니다.

같은 옵션이라도 등급이 다르면 범위가 달라지므로, 괄호만 보고 좋다 나쁘다를 판단할 수는
없습니다. 중괄호 줄의 등급과 같이 봐야 합니다. `등급: 1` 의 하단이 `등급: 3` 의 상단보다
높은 경우가 흔합니다.

## 줄 끝에 붙는 주석

가끔 옵션 줄 뒤에 설명이 더 붙습니다.

```
심연 홈 1개 — 변경이 불가능한 값
```

`변경이 불가능한 값` 은 이 수치가 무작위가 아니라 고정이라는 뜻입니다. 범위가 없으니
재련해도 달라지지 않습니다.

중괄호 줄 자체의 끝에 붙는 경우도 있습니다.

```
{ 접미어 속성 부여 "- 엘더" (등급: 1) — 원소, 저항  — 20% 증가 }
```

뒤쪽 `20% 증가` 는 그 옵션에 적용된 보정입니다. 촉매를 발랐거나 영향력으로 강화된
경우에 나타납니다.

## 이 정보가 그대로 넘어갑니다

[아이템 변환기](/)는 이 형식을 그대로 처리합니다. 중괄호 줄도, 수치 뒤 괄호도
영문으로 바꿔서 내보냅니다.

```
{ Prefix Modifier "Overwhelming" (Tier: 2) — Damage, Elemental, Attack }
38(37-42)% increased Elemental Damage with Attack Skills
```

Path of Building 도 이 형식을 그대로 읽습니다. 그러니 **고급 정보를 켠 채로 복사해도
아무 문제가 없습니다.** 오히려 등급과 범위 정보가 함께 넘어가서, POB 에서 옵션을
손볼 때 참고가 됩니다.

수치 뒤 괄호가 이상해 보여서 지우고 넣는 분들이 있는데 그럴 필요 없습니다.

## 변환기가 이걸 어떻게 처리하나

한 가지 짚어 둘 것이 있습니다. 이 중괄호 줄과 수치 범위는 **번역 사전에 없습니다.**
사전은 게임의 옵션 문구를 담고 있을 뿐, 고급 정보 표시가 만들어내는 껍데기는
포함하지 않습니다.

그래서 변환기는 이 부분을 사전이 아니라 별도의 표로 처리합니다. `접두어 → Prefix`,
`등급 → Tier` 같은 대응을 손으로 넣어 둔 것입니다.

수치 범위 쪽은 조금 다르게 풀었습니다. 사전에서 옵션을 찾을 때 숫자를 지우고 맞춰
보는데, `38(37-42)` 처럼 괄호가 붙으면 그 괄호까지 같이 지웁니다. 그러면 사전의
`{0}% 증가` 와 몸통이 맞아떨어지고, `38(37-42)` 는 통째로 숫자 자리에 잡혀 영문
결과에도 그대로 실려 나갑니다.

덕분에 고급 정보를 켜든 끄든 같은 사전 하나로 처리됩니다.
